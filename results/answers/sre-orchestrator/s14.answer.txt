## Restarts in demo-broken
| Pod | Status | Restarts (last hour / total) | Cause |
|---|---|---|---|
| `cache-7d9bbbd4cc-kr5sx` | CrashLoopBackOff | 12 / 47 | OOMKilled (exit 137) |
| `worker-59c46dcdc4-mtt5x` | CrashLoopBackOff | 12 / 47 | Application error (exit 1) |

- **`cache`:** it runs `stress --vm 1 --vm-bytes 200M` with a 64Mi memory limit. The container allocates about 200MiB and the kernel kills it on every start. This is a per-container limit being hit, not node memory pressure.
- **`worker`:** the troubleshooter's log quote is `config file /etc/worker/config.yaml not found`. The container deliberately exits 1, and there is no config volume mounted. This has nothing to do with resources.
